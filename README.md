1. Почему максимум нельзя всегда начинать с `0`?

Ответ: Потому что может быть ошибка, если в списке только отрицательные числа 

2. Что означает `-1` после поиска индекса?

Ответ: Значит данный элемент не найден

3. Чем сумма отличается от подсчёта элементов?

Ответ: сумма это сложение всех чисел а подсчет элементов определяет количество элементов
